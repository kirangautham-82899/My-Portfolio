## About

Personal developer portfolio showcasing my work, research, and experience — built for speed, visual quality, and accessibility.

**→ [View live](https://my-portfolio-alpha-ochre-20.vercel.app/)**

---

## Built with

<div align="center">

| Layer | Tools |
|:------|:------|
| Framework | Next.js 15 (App Router) · React 19 · TypeScript |
| Styling | Tailwind CSS v4 · CSS custom properties |
| Animation | Framer Motion · GSAP ScrollTrigger · Lenis smooth scroll |
| 3D | Three.js — neural network scene with orbiting ring and particles |
| Contact | Formspree — real email delivery |
| Deployment | Vercel — auto-deploy on push |

</div>

---

## Sections

- **Hero** — Three.js neural-network scene, lazy-loaded on idle
- **About** — Focus areas and education
- **Skills** — Animated proficiency bars
- **Experience** — Timeline at Sustains.ai (intern → full-time)
- **Projects** — Case-study cards with tech tags and GitHub links
- **Research** — Publication, achievements, certifications, leadership
- **Tech Stack** — Full tools and languages grid
- **Contact** — Live Formspree form

## Run locally

```bash
git clone https://github.com/kirangautham-82899/My-Portfolio.git
cd My-Portfolio
pnpm install
pnpm dev
```
